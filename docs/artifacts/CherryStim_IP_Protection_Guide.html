Registration Strategy

Benefits of Federal Registration

  • Statutory damages: Up to $150,000 per work for willful infringement (without proving actual damages)
  • Attorney's fees: Recoverable in infringement suits with registered works
  • Prima facie evidence: Registration is evidence of copyright validity and ownership
  • Customs recording: U.S. Customs can seize infringing imports at the border
  • Public record: Constructive notice of copyright claim worldwide

Software Copyright Specifics

The CherryStim codebase should be registered as a literary work via eCO. Key considerations:

  • Deposit first 25 and last 25 pages of source code (with trade secrets redacted)
  • Register the compilation of code, not individual functions
  • Update registration with each major version release
  • Open-source dependencies (MIT/Apache licensed) are excluded from the claim
  • Proprietary modules (moderation engine, filter engine, card program logic) are the core claim

DMCA Considerations

Register a DMCA agent with the Copyright Office for takedown notice handling. This protects the platform from liability for user-generated content while enabling rapid content removal.

Protection Measures

Required under Defend Trade Secrets Act (DTSA) and state UTSA laws:

  • Non-Disclosure Agreements (NDAs): All employees, contractors, partners, and beta testers must sign NDAs before accessing proprietary information
  • Access Controls: Role-based access in Supabase (RLS), service role key limited to server-side seed script
  • Environment Variable Security: Secrets stored in .env.local (gitignored), never committed to repository. Example file (.env.example) contains placeholder values only
  • Code Repository Access: Private repositories with branch protection rules
  • Employee Exit Procedures: Credential rotation, access revocation, exit NDA reminder
  • Documentation Marking: All confidential documents marked "Confidential" with distribution restrictions
  • Physical Security: Metal card prototypes and design files stored securely

UDRP (Uniform Domain-Name Dispute-Resolution Policy)

If a cybersquatter registers a confusingly similar domain, file a UDRP complaint through WIPO Arbitration Center. Requirements: (1) domain is identical/confusingly similar to your trademark, (2) registrant has no rights to the domain, (3) domain was registered in bad faith. WIPO filing fee: $1,500 per domain (single panelist).
