🔒 Copyright Ownership & Work-for-Hire

All code, designs, and creative works produced by CherryStim employees and contractors are works made for hire under 17 U.S.C. § 101. This ensures the company retains full copyright ownership. Key documentation requirements:

Employee Works

  • Automatic work-for-hire under employment agreement
  • Employment agreement must include IP assignment clause
  • All code committed to company repos is company property
  • Employee inventions disclosure required

Contractor Works

  • Written work-for-hire agreement required BEFORE work begins
  • Supplemental IP assignment as backup
  • Specify all deliverables in scope of work
  • Retain right to modify and create derivative works

Patent Opportunities

Several CherryStim innovations qualify for utility patent protection. These are novel, non-obvious technical inventions implemented in the platform codebase. Provisional patent applications ($320) should be filed immediately to establish priority dates.

🎭

Patent 1: Mode-Adaptive Emoji Rendering System

Source: lib/emojis.ts → getEmojiRenderConfig()

Innovation: A system that dynamically adapts emoji rendering based on the current streaming mode (2D / 3D / VR / Immersive). The system adjusts 3D model usage, physics simulation, haptic feedback, VR interaction capability, particle count (50→200), and animation style in real-time based on client capabilities.

25 Custom Emojis 4 Render Modes Physics Simulation Haptic Integration
⚖️

Patent 2: Asymmetric Weighted Rating System

Source: lib/ratings.ts → computeWeightedRating()

Innovation: A bidirectional rating system with role-asymmetric weighting where client-to-performer ratings carry reduced weight (0.25) compared to performer-to-client ratings (1.0). Includes automated bad-pattern detection (average < 40 over 5+ ratings in 30-day window) with 14-day access blocking, and a premium bypass mechanism for low-rated users.

1/4 Weight Protection Bad Pattern Detection Premium Bypass
🎯

Patent 3: Multi-Step Onboarding Flow with Tier-Gated Steps

Source: lib/onboarding.ts → getStepsForTier()

Innovation: A 12-step onboarding flow where step availability is dynamically gated by the user's selected tier (Rising → Virtuoso). Higher tiers unlock additional steps for fragrance selection, lingerie sizing, swimwear, silk robes, and premium equipment. Includes real-time supplier order tracking with 11 status stages and multi-vendor fulfillment coordination.

👓

Patent 4: AR Filter Tier-Gating with Mode Adaptation

Source: lib/filters.ts → canClientAccessFilter()

Innovation: A system that restricts AR filter access based on user subscription tier (Basic → Platinum) and streaming mode (2D / 3D / VR / Immersive). Each of 18 filters has specific tier requirements, mode support, and render complexity ratings. Client tiers progressively unlock filter categories.

⏰ Patent Timeline & Process

Month 0: File provisional patent applications ($320 each). Establishes priority date. 12-month window to file non-provisional.
Month 1-6: Conduct prior art search. Refine claims based on search results. Identify potential overlapping patents.
Month 8-11: Prepare and file non-provisional patent applications with patent attorney. Include detailed specifications and drawings.
Month 12-36: USPTO examination period. Respond to office actions. Negotiate claims with examiner.
Month 24-48: Patent grant. 20-year protection from filing date. Maintenance fees due at 3.5, 7.5, and 11.5 years.

🛡️ UDRP Dispute Resolution

If a third party registers a confusingly similar domain, CherryStim can file a Uniform Domain-Name Dispute-Resolution Policy (UDRP) complaint through WIPO:

ElementRequired Proof
Identical or confusingly similarDomain is identical/similar to CherryStim trademark
No legitimate interestRespondent has no rights to the name
Bad faith registrationDomain registered to exploit brand or extort payment

Cost: $1,500 single panelist / $4,000 three-panelist. Timeline: 45-60 days. Success rate: ~85% for trademark holders with clear rights.

IP Enforcement Playbook

When infringement is detected, CherryStim follows a graduated enforcement protocol. Early action is critical — delay can weaken legal standing and embolden infringers.

🔍 Infringement Detection Sources

Automated Monitoring

  • Corsearch: Trademark watch service across 200+ jurisdictions
  • Google Alerts: Web mentions of brand terms
  • Domain Watch: New registrations containing "cherrystim"
  • App Store Search: Weekly scans of iOS and Android stores
  • Social Media Crawl: Instagram, TikTok, Twitter brand mentions

Human Intelligence

  • Employee reports of competitor copying
  • Customer/dancer reports of impersonation
  • Industry event intelligence
  • Competitor product analysis
  • Developer community reports (GitHub, npm)

📋 Graduated Enforcement Protocol

Level 1: Cease & Desist Letter — Formal legal notice demanding immediate cessation of infringing activity. Sets 14-day compliance deadline. Sent via certified mail and email. Cost: $500-2,000 (attorney drafted).
Level 2: Platform Takedowns — DMCA notices to hosting providers, app store takedown requests, social media platform reports. Simultaneously file UDRP for domain disputes. Cost: $1,500-3,000 per action.
Level 3: Administrative Proceedings — File TTAB opposition/cancellation at USPTO. File UDRP complaint via WIPO for domain disputes. File ITC complaint for import-related infringement. Cost: $3,000-15,000.
Level 4: Federal Litigation — File trademark/copyright/patent infringement suit in U.S. District Court. Seek injunctive relief, damages, and attorney's fees. Cost: $50,000-500,000+.
