Onboarding Flows
From application to welcome box — every step mapped

  1. Application
    Submit online application with ID verification
  2. Review
    CherryStim team reviews within 24–48 hours
  3. Approval
    Welcome email with account activation link
  4. Profile Setup
    Complete profile, bio, photos, and preferences
  5. Tier Selection
    Choose package tier based on goals
  6. Address Confirm
    Verify shipping address for welcome box
  7. Card Issuance
    Metal debit card minted and personalized
  8. Box Assembly
    Welcome package curated per tier selection
  9. Quality Check
    Each box inspected before gold seal applied
  10. Shipping
    Express tracked delivery via premium carrier
  11. Unboxing
    Welcome email triggers with setup guides
  12. Go Live
    First stream setup with dedicated support

CLIENT — 8 STEPS

  1. Registration
    Create account with email or social login
  2. Verification
    Age and identity verification (18+)
  3. Preferences
    Select gender package preference
  4. Subscription
    Choose membership plan and payment method
  5. Address
    Confirm shipping for welcome package
  6. Fulfillment
    Package assembled and shipped
  7. Delivery
    Track package to doorstep
  8. Explore
    Full platform access unlocked
