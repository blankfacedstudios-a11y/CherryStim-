Section 06
GoDaddy DNS
Domain configuration for cherrystim.com

Configure the following DNS records in GoDaddy DNS Management for the cherrystim.com domain. Allow up to 48 hours for global DNS propagation.

Type Name Value TTL
CNAME www cname.vercel-dns.com 600
A @ 76.76.21.21 600
verify-dns.sh
# Verify DNS propagation
$ dig cherrystim.com +short
76.76.21.21

$ dig www.cherrystim.com CNAME +short
cname.vercel-dns.com.

✓ DNS records verified
💡 SSL Certificate
Vercel automatically provisions and renews SSL certificates via Let's Encrypt once DNS records propagate. Both cherrystim.com and www.cherrystim.com will be served over HTTPS.
Section 07
Environment Variables
Complete reference — all 7 required variables
Variable Source Description
NEXT_PUBLIC_SUPABASE_URL Supabase Project API URL from Supabase dashboard → Settings → API
NEXT_PUBLIC_SUPABASE_ANON_KEY Supabase Anonymous/public API key for client-side Supabase access
SUPABASE_SERVICE_ROLE_KEY Supabase Service role key for server-side operations (bypasses RLS)
NEXT_PUBLIC_LIVEKIT_URL LiveKit WebSocket URL for LiveKit Cloud (wss://xxx.livekit.cloud)
LIVEKIT_API_KEY LiveKit API key for generating room tokens server-side
LIVEKIT_API_SECRET LiveKit API secret paired with key for JWT token signing
NEXT_PUBLIC_APP_URL Config Public app URL (localhost:3000 for dev, cherrystim.com for prod)

Section 08
Post-Deployment
Verify everything is working in production
  • ✓
    Homepage Loads — Navigate to cherrystim.com and verify the landing page renders correctly with all assets loaded.
  • ✓
    SSL Certificate Active — Confirm the padlock icon appears in the browser. Check both cherrystim.com and www.cherrystim.com redirect to HTTPS.
  • ✓
    Authentication Flow — Test sign-up, login, and password reset flows. Verify the admin account timjackson2nd@gmail.com can access the admin dashboard.
  • ✓
    Database Connection — Verify Supabase connection by checking user profiles load and real-time subscriptions are active.
  • ✓
    LiveKit Streaming — Create a test room and verify video/audio streaming works. Test with at least 2 participants.
  • ✓
    API Routes — Test all API endpoints return correct responses. Check /api/auth and /api/livekit/token endpoints.
  • ✓
    Mobile Responsive — Test on mobile devices or Chrome DevTools device emulation. Verify all breakpoints render correctly.
  • ✓
    Error Monitoring — Verify error tracking is configured and test errors are captured. Check Vercel Analytics dashboard.
  • ✓
    Performance Audit — Run Lighthouse audit. Target scores: Performance > 90, Accessibility > 95, SEO > 90, Best Practices > 90.
✓ Deployment Complete
All systems verified. CherryStim is live at cherrystim.com. Monitor the Vercel dashboard for deployment status and error tracking.
