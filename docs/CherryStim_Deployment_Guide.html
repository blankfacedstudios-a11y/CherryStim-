1 Create a Vercel Account

Vercel is the company that makes Next.js (which CherryStim is built on). They host your website for free.

  1. Open your web browser
  2. Go to: vercel.com/signup
  3. You'll see options to sign up. Click "Continue with GitHub"
  4. GitHub will ask you to authorize Vercel. Click "Authorize Vercel"
  5. Vercel may ask you to choose between "Hobby" (free) and "Pro" ($20/mo). Select "Hobby" for now — you can upgrade later
  6. You're now on your Vercel dashboard. It will be empty. That's normal.
Your Vercel dashboard URL is vercel.com/dashboard — bookmark this page.

2 Import Your GitHub Repository to Vercel

Now we connect your CherryStim code to Vercel so it can build and host it.

  1. On your Vercel dashboard, click the "Add New…" button (top right), then click "Project"
  2. You'll see a list of your GitHub repositories. Look for "CherryStim-" (under blankfacedstudios-a11y)
  3. If you don't see it, click "Adjust GitHub App Permissions" and grant Vercel access to the CherryStim- repository
  4. Click "Import" next to the CherryStim- repository
  5. You'll see the "Configure Project" screen. Important settings:
    • Project Name: Leave as cherrystim or type cherrystim
    • Framework Preset: Should auto-detect Next.js ✅
    • Root Directory: Leave as ./ (the default)
  6. Look for a "Branch" dropdown or setting. Change it to: cursor/cherrystim-immersive-platform-bf9b
    This is critical! The main branch only has a README. All the actual code is on the cursor/cherrystim-immersive-platform-bf9b branch.
  7. Click "Deploy"
  8. Wait 2–3 minutes. You'll see a build log. When it says "Congratulations!" with confetti, your site is deployed!
  9. Vercel gives you a temporary URL like cherrystim-xxxx.vercel.app. Click it to verify the site loads.
The site will load but login won't work yet — we need to set up the database (Supabase) first. That's Step 3.
Your Vercel project URL: cherrystim-_______.vercel.app (write it down)

3 Create a Supabase Cloud Project

  4. Sign in with "Continue with GitHub" (same GitHub account)
  5. You'll see your dashboard. Click "New Project"
  6. Fill in the form:
    • Organization: Click "Create a new organization" if needed, name it CherryStim
    • Project name: Type cherrystim-production
    • Database Password: Click "Generate a password" — COPY AND SAVE THIS PASSWORD SOMEWHERE SAFE. You will need it later.
    • Region: Select West US (North California) — closest to your California base

  8. Wait 2–3 minutes for the project to set up. You'll see a loading screen with "Setting up your project…"

4 Run Database Migrations

We need to create the database tables (profiles, wallets, transactions, etc.) in your cloud Supabase.

  1. In your Supabase project dashboard, click "SQL Editor" in the left sidebar (it looks like a terminal icon)
  2. Click "New Query" (top left button)
  3. Copy the ENTIRE contents below and paste it into the SQL editor:
create extension if not exists "uuid-ossp";

create table profiles (
  id uuid primary key references auth.users,
  display_name text,
  role text check (role in ('client', 'dancer', 'admin')),
  tier text default 'Pro',
  created_at timestamp default now()
);

create table coin_wallets (
  user_id uuid primary key references profiles(id),
  balance bigint default 0
);

create table dancer_profiles (
  user_id uuid primary key references profiles(id),
  bio text,
  gear_owner text default 'cherrystim'
);

create table transactions (
  id uuid primary key default uuid_generate_v4(),
  from_user uuid references profiles(id),
  to_user uuid references profiles(id),
  amount bigint,
  type text,
  created_at timestamp default now()
);
  1. Click the green "Run" button (or press Ctrl+Enter / Cmd+Enter)
  2. You should see "Success. No rows returned" — that means it worked!
That's it! Your database tables are created. The "admin" role was included in the profiles check constraint already.

7 Redeploy on Vercel

Environment variables only take effect after a new deployment. Let's trigger one.

  1. In your Vercel project, click the "Deployments" tab (top of the page)
  2. Find the most recent deployment (it's at the top of the list)
  3. Click the three dots (⋯) on the right side of that deployment
  4. Click "Redeploy"
  5. A popup will appear. Click "Redeploy" again to confirm
  6. Wait 2–3 minutes for the build to complete
  7. Once it shows a green checkmark ✅, your site is live with the database connected!

9 Connect GoDaddy Domain to Vercel

Now we point www.cherrystim.com to your Vercel deployment. This has two parts.

Part A: Tell Vercel about your domain

  1. Go to your Vercel project: vercel.com/dashboard → click "cherrystim"
  2. Click "Settings" tab
  3. Click "Domains" in the left sidebar
  4. In the input field, type cherrystim.com and click "Add"
  5. Vercel will ask how to configure it. Select "Add www.cherrystim.com and redirect cherrystim.com to it" (the recommended option)
  6. Click "Add"
  7. You'll see both cherrystim.com and www.cherrystim.com listed, both showing ❌ "Invalid Configuration" — that's expected! We need to update GoDaddy next.

Part B: Update DNS records in GoDaddy

  1. Open a new tab and go to: dcc.godaddy.com
  2. Log in to your GoDaddy account
  3. Find cherrystim.com in your domain list and click on it
  4. Click "DNS" or "Manage DNS" or "DNS Records"
  5. You'll see a table of DNS records. We need to change/add two records:

Record 1: The A Record (for cherrystim.com without www)

  1. Find the row where Type is A and Name is @
  2. Click the pencil/edit icon on that row
  3. Change the Value to: 76.76.21.21
  4. Set TTL to: 600 (or "10 minutes" or "1/2 Hour" — whatever is lowest)
  5. Click "Save"
If there are MULTIPLE A records for @, delete the extras so only ONE remains with value 76.76.21.21.

Record 2: The CNAME Record (for www.cherrystim.com)

  1. Look for a row where Type is CNAME and Name is www
  2. If it exists: click the pencil/edit icon and change the Value to: cname.vercel-dns.com
  3. If it does NOT exist: click "Add New Record" and fill in:
    • Type: CNAME
    • Name: www
    • Value: cname.vercel-dns.com
    • TTL: 600
  4. Click "Save"

Your final DNS records should look like this:

TypeNameValueTTL
A@76.76.21.21600
CNAMEwwwcname.vercel-dns.com600
Do NOT delete any MX records (those are for email). Only change the A and CNAME records as described above.
